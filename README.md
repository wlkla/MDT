# MDT - 鼠标桌面切换工具

## 概述

MDT 是一个为 macOS 用户设计的轻量级桌面应用程序。它允许用户将鼠标的两个侧键（X1 和 X2）映射到"切换到左侧桌面"和"切换到右侧桌面"的功能，从而极大地提升了在多个虚拟桌面间的工作效率。

应用提供了一个直观的图形界面，用户可以轻松地对调两个侧键的功能。程序会常驻在系统托盘中，方便随时显示/隐藏主窗口或退出程序。

## 主要功能

### 核心功能
- **侧键映射**：将鼠标侧键 X1 和 X2 分别绑定到切换左右桌面的功能
- **功能对调**：通过拖拽界面中的"左桌面"和"右桌面"标签，可以轻松交换 X1 和 X2 键对应的功能
- **系统托盘**：程序在后台运行，并显示在系统托盘中，不干扰正常工作
- **图形化界面**：直观地展示当前按键的功能分配

### 增强功能
- **配置持久化**：自动保存用户的按键设置，重启后无需重新配置
- **窗口位置记忆**：记住窗口位置，下次打开时自动恢复
- **权限检测**：启动时自动检测辅助功能权限，并提供友好的设置引导
- **快捷键支持**：按 `Ctrl+H` 快速隐藏窗口
- **双击托盘**：双击托盘图标快速显示/隐藏窗口
- **视觉反馈**：按下鼠标侧键时，界面会闪烁提示
- **完善日志**：记录运行日志到 `~/.mdt/mdt.log`，便于排查问题
- **Feed 数据处理**（可选）：自动监听剪切板中的 Feed 数据并格式化处理

## 技术栈

- **语言**: Python 3
- **GUI 框架**: PyQt5
- **UI 设计**: Qt Designer
- **macOS 事件监听**: PyObjC (Quartz)
- **打包**: PyInstaller

## 如何使用

### 1. 从源码运行

在运行之前，请确保已经安装了所需的依赖库。

**安装依赖:**
```bash
pip install pyqt5 pyobjc-core pyobjc-framework-quartz
```

**运行程序:**
```bash
python3 MDT.py
```

> **注意**: 首次运行时，macOS 可能会提示需要"辅助功能"权限来允许此应用控制电脑。程序会自动检测权限并显示设置引导。

### 2. 构建应用

项目提供了一个 `build.sh` 脚本来自动化构建过程，它会使用 PyInstaller 将项目打包成一个独立的 `.app` 文件。

**安装构建工具:**
```bash
pip install pyinstaller
```

**执行构建:**
```bash
sh build.sh
```

构建成功后，你会在新生成的 `dist` 文件夹中找到 `MDT.app`。你可以将它移动到"应用程序"文件夹中使用。

## 使用技巧

### 基本操作
1. **启动应用**：双击 `MDT.app` 或运行 `python3 MDT.py`
2. **配置按键**：拖拽"左桌面"或"右桌面"标签到 X1 或 X2 区域
3. **使用侧键**：按下鼠标 X1 或 X2 键切换桌面

### 快捷操作
- **Ctrl+H**：隐藏窗口
- **双击托盘图标**：显示/隐藏窗口
- **右键托盘图标**：打开菜单（显示、退出）

## 权限设置

MDT 需要"辅助功能"权限才能监听鼠标事件。首次运行时会自动提示，您也可以手动设置：

1. 打开"系统偏好设置"（系统设置）
2. 进入"安全性与隐私"（隐私与安全性）→"隐私"→"辅助功能"
3. 点击左下角的锁图标解锁
4. 勾选 MDT（或您使用的终端/IDE）
5. 重启 MDT 应用

## 故障排查

### 鼠标侧键无响应
- 检查是否已授予辅助功能权限
- 查看日志文件 `~/.mdt/mdt.log` 了解详情
- 确认鼠标支持 X1/X2 侧键

### 配置丢失
- 配置文件位于 `~/.mdt/config.json`
- 如果配置损坏，删除该文件后重启应用会重新创建

### Feed 数据处理功能不工作（打包后）
**问题原因：** 打包后的应用使用 `subprocess` 调用 `pbpaste`/`pbcopy` 可能失败

**解决方案：** 已使用原生 macOS API (AppKit.NSPasteboard) 替代

**验证方法：**
```bash
# 测试剪切板功能是否正常
python3 test_clipboard.py
```

**检查日志：**
```bash
# 查看应用启动时是否使用了原生 API
tail -f ~/.mdt/mdt.log
# 应该看到: "使用原生 macOS 剪切板 API (AppKit.NSPasteboard)"
```
